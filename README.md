# Rvphv Love Site

Frontend statique conçu pour Raphaela / Rvphv 👾♥️.

- 5 directions graphiques : Vaporwave, Graffiti, Mixed Media, Coquette, Scrapbook
- Carrousel animé, parallaxe visuelle et transitions au scroll
- Calendrier Mercredi → Dimanche, Matinée / Après-midi / Nuit
- Les disponibilités sont stockées localement dans le navigateur (`localStorage`) en attendant le backend Supabase.

Ouvrir `index.html` directement ou déployer sur Vercel.
